States and expressions · example with Bolt

6 states, one language

State color shows up on the antenna, the notch underline, and the session dot. Eye shape also differs per state, so the status stays readable even if you can't tell colors apart.

Sleeping

Trigger

No active session for 2 minutes

Motion

Slow 4-second breathing, eyes shut, zzz

Sound

None

Notch

Normal size, robot peeks out below

Thinking

Trigger

Prompt sent, no tool call yet

Motion

Eyes glance up, dots in a bubble

Sound

None

Notch

Widens a little: "Thinking…"

Working

Trigger

Hook PreToolUse / PostToolUse

Motion

Typing on a laptop, body sways every 0.5 s

Sound

None

Notch

Widens: tool name, file, and progress

Needs you

Trigger

Hook Notification / PermissionRequest

Motion

Hopping, wide eyes, pulsing exclamation mark

Sound

Soft "Beep-beep", at most once a minute

Notch

Orange, "Review" button

Done

Trigger

Hook Stop

Motion

Jumps with squash and stretch, one burst of confetti

Sound

"Ding"

Notch

Blue, 4-second summary, then back to sleep

Error

Trigger

Tool failed or exit code is not 0

Motion

Spiral eyes, dizzy wobble, puffs of smoke

Sound

Soft "Bwomp"

Notch

Red, one-line error message
