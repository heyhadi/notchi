The buddies

Twelve of them. One per agent, if you like.

They watch your cursor. Hover to cycle their moods, click to adopt one: it moves into the notch up top and into the playground below.

Playground

Grab one. Drop it. Make them collide.

In the app they walk along your Dock while an agent works. Here they're all yours: drag and let go, poke a few times, add friends and watch them bump.

The robot voice

Beeps that sound like a mood.

The default sound pack is wordless droid babble built from gliding blips, synthesized live. In the app sounds are opt-in and go quiet while your microphone is in use.

Safety first

It never approves what it shouldn't.

  • Risky commands can't be approved here.
    The hook answers right away with no decision, so the agent asks in its own terminal.
  • Only agents with a real permission hook get buttons.
    Everywhere else Notchi only shows status.
  • Local by design.
    Hooks talk to the app over a Unix socket in your home folder. No server, no account.
  • Every file it writes is labelled and reversible.
    A marker and a timestamped backup on every settings change.

Get it

Download, drag, done.

macOS 14 or later, Apple Silicon or Intel. Notch Macs look best; others get the same panel under the menu bar.

Notchi isn't notarized yet, so macOS blocks the first launch: open it once, then System Settings → Privacy & Security → Open Anyway. Or build it yourself from source.

Download .dmgView on GitHub
# or build from source
git clone https://github.com/heyhadi/notchi.git
cd notchi

# build and open the app
./scripts/make-app.sh
open build/NotchBuddy.app

# run the tests
swift test

# then: menu bar icon → Settings → Agents → Connect
