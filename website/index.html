What it does

Everything an agent wants from you, one glance away.

The notch stays out of the way until something needs you. Approvals, replies and a daily token budget live in the same place, and nothing leaves your Mac.

$ curl https://get.example/install.sh | bash
Risky: pipes a download into a shell. Answer it in your terminal.

Approve from the notch, never the risky stuff

Safe permission requests get Allow and Deny buttons for Claude Code, Codex and OpenCode. Commands that look dangerous are handed straight back to the agent's own prompt.

Type in the notch and your message reaches Claude Code in the middle of its turn. The box tells you honestly when an agent is idle and your message can only wait.

Local by design

Hooks talk to the app over a socket inside your home folder. Session history stays in a file you can delete from Settings.

The buddies

Pick one. Watch it react.

Every buddy has the same moods: asleep, thinking, working, needs you, done and error. Tap one to move it into the demo above.

The robot voice

Beeps that sound like a mood, not a notification.

The default sound pack is wordless droid babble, synthesized from gliding blips. Press a card to hear it. Needs-you rises like a question, done trills upward, errors sag.

Turns on after your first press. In the app, sounds are off until you enable them and mute themselves while your microphone is in use.

Safety first

It never approves what it should not.

  • Risky commands are never approvable here.
    The hook answers immediately with no decision, so the agent asks in its own terminal.
  • Only agents with a real permission hook can be approved.
    Everywhere else Notch Buddy only shows status.
  • Every file it writes is labelled and reversible.
    Settings changes carry a marker and a timestamped backup, and removal only touches its own entries.

Run it

A Swift package. Build it in a minute.

Needs macOS 14 or later and the Swift toolchain. A Mac with a notch looks best; others get the same panel under the menu bar.

# build and open the app
./scripts/make-app.sh
open build/NotchBuddy.app

# run the tests
swift test

# then: menu bar icon → Settings → Agents → Connect
